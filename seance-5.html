1. Les 4 règles d'or du cahier des charges

Avant de vous lancer dans le code, votre proposition de jeu doit valider ces quatre piliers essentiels :

  • L'objectif moteur : Travailler un geste ciblé — précision du clic, suivi d'un mouvement, maintien immobile ou inclinaison (souris ou carte micro:bit).
  • L'accessibilité (public senior) : Gros éléments visuels, contrastes élevés, vitesse lente ou réglable, règles immédiates et aucun « Game Over » brutal (on encourage et on laisse le temps).
  • Le niveau technique (Début d'année + listes légères) : Variables, conditions (if/else), boucles (for, while), fonctions (def), module random, événements Tkinter (bind) et listes simples (couleurs, coordonnées, messages positifs).
  • Le travail à trois : Découpage clair en deux fichiers (main.py pour l'interface/événements et fonctions.py pour la logique) avec un rôle défini par élève.
📅 Jalons du projet : Première version jouable attendue pour le 17 décembre • Version finale complète (main.py, fonctions.py, diaporama .pdf et notes .txt) pour le 1er avril.

2. Catalogue des 6 pistes de mini-jeux

Piste A : Précision du clic et réflexes doux

  • Concept 1 — « La cueillette au verger » (ou « Attrape-papillons ») : De gros fruits apparaissent un par un à des coordonnées aléatoires (random.randint). Pas de chrono stressant : le fruit attend le clic et affiche un message positif pioché dans une liste.
  • Concept 2 — « Le piano lumineux » (Coordination & mémoire douce) : 4 gros pavés de couleur (["red", "blue", "green", "yellow"]) s'allument à rythme libre ; le joueur clique sur la touche correspondante.

Piste B : Suivi de trajectoire et stabilité

  • Concept 3 — « Le facteur du village » : Déplacer une icône le long d'un chemin très large (<Motion> ou boutons micro:bit). En cas de sortie de route, le personnage rebondit doucement au centre du chemin avec un signal visuel bienveillant.
  • Concept 4 — « L'arrosage du jardin » : Maintenir le curseur immobile sur une fleur fanée pendant 2 secondes (boucle after() de Tkinter) pour la faire éclore, sans avoir besoin de cliquer rapidement.

Piste C & D : Tri par glisser-déposer ou carte micro:bit

  • Concept 5 — « Le tri du marché » : Glisser-déposer (<B1-Motion>, <ButtonRelease-1>) un aliment central vers deux très grands paniers latéraux, avec retour doux au centre en cas de lâcher hors zone.
  • Concept 6 — « L'équilibre sur le fil » (micro:bit) : Incliner la carte à gauche ou à droite (accéléromètre) pour déplacer un large panier et rattraper des objets chutant lentement.

4. Prototypage Python 1 : Module fonctions.py (Cueillette & Encouragements)

Avant de créer l'interface graphique Tkinter, testez ici deux fonctions essentielles de votre fichier fonctions.py :

  • choisir_encouragement(messages) : renvoie un message tiré au hasard dans la liste messages (avec random.randint ou random.choice).
  • clic_dans_cible(clic_x, clic_y, cible_x, cible_y, rayon) : renvoie True si la distance au carré entre le clic et le centre de la cible est inférieure ou égale à rayon ** 2 : (clic_x - cible_x)**2 + (clic_y - cible_y)**2 <= rayon**2.

5. Squelette Tkinter prêt à l'emploi (main.py)

Ce modèle complet (à exécuter dans Thonny ou VS Code sur votre ordinateur) met en place une fenêtre accessible de 800×600 avec de grosses cibles, un sélecteur de taille et des encouragements sans aucun échec punitif. Vous pouvez le modifier librement pour l'adapter au jeu choisi par votre équipe :

📄 Code de départ pour main.py (La Cueillette au Verger)

import tkinter as tk
import random

# --- PARAMÈTRES D'ACCESSIBILITÉ ---
LARGEUR, HAUTEUR = 800, 600
rayon_cible = 45  # Grosse cible par défaut pour seniors
score = 0
messages = ["Bravo !", "Superbe précision !", "Continuez comme ça !", "Quelle adresse !"]

def nouvelle_cible():
    canvas.delete("cible")
    x = random.randint(rayon_cible + 20, LARGEUR - rayon_cible - 20)
    y = random.randint(rayon_cible + 20, HAUTEUR - rayon_cible - 20)
    canvas.create_oval(
        x - rayon_cible, y - rayon_cible,
        x + rayon_cible, y + rayon_cible,
        fill="#ef4444", outline="#ffffff", width=3, tags="cible"
    )

def gerer_clic(event):
    global score
    # Récupère les coordonnées de la cible affichée
    coords = canvas.coords("cible")
    if coords:
        cx = (coords[0] + coords[2]) / 2
        cy = (coords[1] + coords[3]) / 2
        if (event.x - cx)**2 + (event.y - cy)**2 <= rayon_cible**2:
            score += 1
            label_score.config(text=f"Récolte : {score}  |  {random.choice(messages)}")
            nouvelle_cible()
        else:
            # Aucun échec punitif : on encourage simplement
            label_score.config(text=f"Récolte : {score}  |  Presque ! Visez bien le centre du fruit.")

def changer_taille():
    global rayon_cible
    rayon_cible = 30 if rayon_cible == 45 else 45
    btn_taille.config(text=f"Taille cible : {'Grande' if rayon_cible == 45 else 'Moyenne'}")
    nouvelle_cible()

# --- INTERFACE GRAPHIQUE ---
fenetre = tk.Tk()
fenetre.title("Atelier Motricité — La Cueillette au Verger")

barre_haut = tk.Frame(fenetre, bg="#0f172a", pady=10)
barre_haut.pack(fill="x")

label_score = tk.Label(barre_haut, text="Récolte : 0  |  Cliquez sur le fruit !",
                       font=("Arial", 16, "bold"), fg="#f8fafc", bg="#0f172a")
label_score.pack(side="left", padx=20)

btn_taille = tk.Button(barre_haut, text="Taille cible : Grande", font=("Arial", 12, "bold"),
                       command=changer_taille, bg="#6366f1", fg="white", padx=12, pady=5)
btn_taille.pack(side="right", padx=20)

canvas = tk.Canvas(fenetre, width=LARGEUR, height=HAUTEUR, bg="#ecfdf5")
canvas.pack()
canvas.bind("<Button-1>", gerer_clic)

nouvelle_cible()
fenetre.mainloop()
