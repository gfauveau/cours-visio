Maîtriser les structures de contrôle, l'écriture de fonctions et la manipulation de listes simples

1. Synthèse de cours : Les fondamentaux Python

A. Opérateurs et expressions booléennes

  • Opérateurs arithmétiques : +, -, *, / (division décimale), // (quotient entier), % (reste / modulo), ** (puissance).
  • Opérateurs de comparaison : == (égal à), != (différent de), <, <=, >, >=. Ils renvoient toujours un booléen (True ou False).
  • Opérateurs logiques : and (et), or (ou), not (non).

B. Structures conditionnelles : if / elif / else

Permettent d'exécuter un bloc d'instructions uniquement si une condition est vérifiée :

  • Syntaxe : Deux-points : à la fin de chaque test et indentation de 4 espaces.
  • Ordre d'évaluation : Python teste les conditions de haut en bas et exécute uniquement le premier bloc vrai (ignorant les elif et else suivants).

C. Les fonctions : def, paramètres et return

Une fonction factorise un traitement réutilisable : elle reçoit des paramètres en entrée et renvoie un résultat en sortie grâce au mot-clé return.

⚠️ Différence fondamentale entre print() et return :
• print(x) affiche une valeur à l'écran pour l'humain, mais la fonction renvoie None (la valeur est perdue pour la suite du programme).
• return x renvoie le résultat au programme appelant (pour le stocker dans une variable ou le tester avec assert) et interrompt immédiatement l'exécution de la fonction.

D. Les listes légères (list)

  • Création et accès : scores = [12, 18, 9] • Indice du premier élément : scores[0] (12) • Dernier élément : scores[-1] (9).
  • Opérations courantes : len(scores) (taille), scores.append(15) (ajout en fin de liste), 18 in scores (test d'appartenance).

3. Exercice Python 1 : Bulletin météo (if / elif / else)

Écrivez la fonction bulletin_meteo(temp) qui renvoie :

  • "Gel" si temp <= 0,
  • "Frais" si 0 < temp < 15,
  • "Doux" si 15 <= temp <= 25,
  • "Chaud" si temp > 25.
meteo.py
Console Python
En attente d'exécution...

✅ Proposition de correction :

def bulletin_meteo(temp):
    if temp <= 0:
        return "Gel"
    elif temp < 15:
        return "Frais"
    elif temp <= 25:
        return "Doux"
    else:
        return "Chaud"

4. Exercice Python 2 : Année bissextile (Logique booléenne)

Une année est bissextile si elle est divisible par 4 et non divisible par 100, ou si elle est divisible par 400.
Consigne : Complétez la fonction est_bissextile(annee) pour qu'elle renvoie True ou False.

bissextile.py
Console Python
En attente d'exécution...

✅ Proposition de correction :

def est_bissextile(annee):
    return (annee % 4 == 0 and annee % 100 != 0) or (annee % 400 == 0)

5. Exercice Python 3 : Filtrer une liste avec append()

Complétez la fonction notes_au_dessus(notes, seuil) qui prend en paramètre une liste de notes et un seuil, et renvoie une nouvelle liste contenant uniquement les notes supérieures ou égales au seuil.

filtrage_liste.py
Console Python
En attente d'exécution...

✅ Proposition de correction :

def notes_au_dessus(notes, seuil):
    resultat = []
    for n in notes:
        if n >= seuil:
            resultat.append(n)
    return resultat

6. Exercice Python 4 : Défi synthèse (Moyenne d'une liste)

Écrivez la fonction moyenne(liste_nombres) qui calcule et renvoie la moyenne arithmétique d'une liste non vide de nombres (sans utiliser sum(), uniquement avec une boucle et len()).

moyenne.py
Console Python
En attente d'exécution...

✅ Proposition de correction :

def moyenne(liste_nombres):
    total = 0
    for valeur in liste_nombres:
        total += valeur
    return total / len(liste_nombres)
