1. Synthèse de cours : Mémoire et Affectation

A. L'analogie de la commode et l'affectation (=)

La mémoire de l'ordinateur fonctionne comme une commode composée de tiroirs étiquetés. Lorsqu'on écrit a = 2, Python vérifie si le tiroir a existe (sinon il le crée), ouvre le tiroir et y dépose 2 en écrasant définitivement l'ancienne valeur.

  • Différence avec les mathématiques : Le signe = est une affectation (et non une égalité). Ainsi, compteur = compteur + 1 (raccourci en compteur += 1) signifie : « prendre la valeur actuelle, ajouter 1, et ranger le résultat dans compteur ».
  • Exécution de droite à gauche : Python évalue d'abord l'expression à droite du =, puis range le résultat dans la variable à gauche.
  • Erreur d'initialisation : Lire une variable qui n'a jamais reçu de valeur déclenche une erreur NameError: name '...' is not defined.

B. Les 4 types fondamentaux et le typage dynamique

Python devine automatiquement le type lors de l'affectation (on peut l'interroger avec la fonction type()) :

  • int (Entier) : Nombres entiers positifs ou négatifs (ex. a = 2). Les calculs sont exacts.
  • float (Flottant) : Nombres décimaux (ex. prix = 0.08). Représentation approchée en binaire.
  • str (Chaîne) : Texte entre guillemets simples ou doubles (ex. nom = 'Harry').
  • bool (Booléen) : Valeur logique True ou False.
⚠️ Piège des flottants en machine : En mathématiques, $0{,}5^2 + 1{,}2^2 = 1{,}3^2$ ($1{,}69 = 1{,}69$). Pourtant, en Python, 0.5**2 + 1.2**2 == 1.3**2 renvoie False à cause des légères erreurs d'arrondi lors du codage binaire des nombres à virgule !

C. Règles et conventions de nommage

  • Règles obligatoires : Lettres (a-z, A-Z), chiffres (0-9) et _ uniquement ; interdit de commencer par un chiffre ; pas d'espaces ni de caractères spéciaux ; sensible à la casse (var_A ≠ var_a) ; mots réservés interdits (if, for, def...).
  • Convention snake_case : Noms explicites en minuscules séparés par des tirets bas, sans accents (ex. compte_epargne_client).
