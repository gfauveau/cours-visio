Les Boucles en Python : for & while

Structures répétitives bornées, non bornées et contrôle d'exécution

📖

1. Synthèse de cours : Structures répétitives

En Python, la structure d'une boucle repose sur deux règles strictes : les deux-points : à la fin de l'en-tête et l'indentation de 4 espaces qui délimite le bloc répété.

A. Les boucles bornées : for et range()

Utilisée lorsque le nombre de répétitions est connu à l'avance ou pour parcourir un itérable (chaîne, liste) :

  • range(n) : génère les entiers de 0 à n - 1 (soit n itérations).
  • range(a, b) : génère les entiers de a à b - 1.
  • range(a, b, pas) : génère de a à b - 1 avec un saut défini (ex. range(2, 10, 2) → 2, 4, 6, 8).
  • Variable muette (_) : Si la variable de boucle n'est pas utilisée dans le bloc, on la nomme par convention for _ in range(5):.

B. Les boucles non bornées : while

Exécute un bloc tant qu'une condition booléenne vaut True. Pour éviter toute boucle infinie, respectez toujours la règle des trois étapes :

  • 1. Initialisation : affectation préalable de la variable de test avant le while.
  • 2. Test : évaluation de la condition dans l'en-tête du while.
  • 3. Modification : mise à jour de la variable de test à l'intérieur du bloc répété.

C. Contrôle d'exécution : break et continue

  • break : interrompt immédiatement la boucle en cours et passe aux instructions suivantes.
  • continue : saute le reste de l'itération actuelle et passe directement au tour de boucle suivant.
💡 Tableau comparatif rapide :
• Boucle for : Nombre d'itérations connu • Arrêt en fin de séquence • Piège : oublier que b est exclu dans range(a, b).
• Boucle while : Nombre d'itérations inconnu • Arrêt quand la condition devient False • Piège : oublier la modification de la variable (boucle infinie).

3. Exercice Python 1 : Somme des entiers de 1 à n

Écrivez la fonction calculer_somme(n) qui renvoie la somme des entiers de 1 à n inclus à l'aide d'une boucle for.

✅ Proposition de correction :

def calculer_somme(n):
    somme = 0
    for i in range(1, n + 1):
        somme += i
    return somme

def compter_voyelles(mot):
    voyelles = 'aeiouyAEIOUY'
    compteur = 0
    for lettre in mot:
        if lettre in voyelles:
            compteur += 1
    return compteur

5. Exercice Python 3 : Boucle while et calcul de seuil

Un capital initial de 120 € augmente de 5 % par an (multiplié par 1.05). À l'aide d'une boucle while, écrivez la fonction annees_pour_doubler(capital_initial) qui renvoie le nombre d'années nécessaires pour que le capital atteigne ou dépasse le double de sa valeur initiale.

✅ Proposition de correction :

def annees_pour_doubler(capital_initial):
    capital = capital_initial
    objectif = capital_initial * 2
    annees = 0
    while capital < objectif:
        capital = capital * 1.05
        annees += 1
    return annees

def table_multiplication(n):
    for i in range(1, 11):
        print(f"{n} x {i} = {n * i}")

🎮 Corrigé Bonus : Jeu de devinette (à tester en local dans Thonny / VS Code)

import random

def deviner_nombre():
    secret = random.randint(1, 20)
    essai = 0
    while essai != secret:
        essai = int(input("Devine le nombre (1-20) : "))
        if essai < secret:
            print("Trop petit !")
        elif essai > secret:
            print("Trop grand !")
    print("Bravo ! Tu as trouvé le nombre secret.")
