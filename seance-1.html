Codage du Texte, de l'Image et du Son

Du bit aux structures Python (boucles bornées et fonctions)

📖

1. Synthèse de cours : Tout est binaire

A. Codage du texte (ASCII & Unicode / UTF-8)

  • ASCII : Code historique sur 7 bits (128 caractères : lettres non accentuées, chiffres, ponctuation).
  • Unicode (UTF-8) : Standard universel (plus de 140 000 symboles, accents, emojis) à taille variable (1 à 4 octets), rétrocompatible avec l'ASCII.
  • En Python : ord('A') renvoie le point de code entier (65) et chr(65) renvoie le caractère ('A').

B. Codage d'une image matricielle (Bitmap)

  • Définition : Nombre total de pixels = Largeur × Hauteur.
  • Profondeur de couleur : Nombre de bits par pixel (1 bit en noir & blanc, 8 bits = 256 niveaux de gris, 24 bits en RVB soit 3 octets : Rouge, Vert, Bleu de 0 à 255).
  • En Python : Une image en niveaux de gris est souvent modélisée par une liste de listes (matrice 2D) et parcourue par deux boucles imbriquées.

C. Codage du son numérique

  • Échantillonnage (f en Hz) : Nombre de mesures par seconde (ex. qualité CD = 44 100 Hz).
  • Quantification (q en bits) : Précision de chaque mesure (ex. 16 bits).
  • Canaux (c) : 1 en mono, 2 en stéréo.
💡 Formule du poids d'un fichier audio brut (non compressé) :
Taille (en bits) = Fréquence (Hz) × Quantification (bits) × Canaux × Durée (s)
(Diviser par 8 pour obtenir des octets, puis par 1000 pour des ko ou 1024 pour des Kio).

✅ Proposition de correction :

def somme_ascii(chaine):
    total = 0
    for caractere in chaine:
        total = total + ord(caractere)
    return total

Une image 3×3 en niveaux de gris (0 à 255) est représentée par une matrice. Complétez la fonction compter_pixels_clairs(image, seuil) qui renvoie le nombre de pixels strictement supérieurs à seuil.

✅ Proposition de correction :

def compter_pixels_clairs(image, seuil):
    compteur = 0
    for ligne in image:
        for pixel in ligne:
            if pixel > seuil:
                compteur += 1
    return compteur

def taille_audio_ko(freq, quantif, canaux, duree):
    taille_bits = freq * quantif * canaux * duree
    taille_octets = taille_bits / 8
    return taille_octets / 1000
